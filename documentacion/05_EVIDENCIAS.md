# Evidencias de la Evaluación 2

## Descripción

Este documento reúne las evidencias visuales del funcionamiento del Sistema Municipal de Soporte TI.

Las capturas permiten demostrar la implementación de:

- Inicio de sesión y registro.
- Acceso según el rol.
- Panel del funcionario.
- Creación de requerimientos.
- Listado y detalle de solicitudes.
- Administración de requerimientos.
- Notificaciones internas.
- Actualización de estado y respuesta.
- Eliminación con SweetAlert2.
- Restricción de acceso mediante error 403.
- Seeder, Factory y registros generados.
- Rutas y métodos HTTP del sistema.

Las evidencias muestran el funcionamiento de las principales características desarrolladas para la Evaluación 2.
